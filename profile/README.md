# UnseenConnect

Клиент для управления **своими** прокси-серверами на ядре **Xray**: подписка, VPN (TUN) и системный прокси, пинг, маршрутизация, обновления.

UnseenConnect **не продаёт VPN-подписки** и не предоставляет серверы — только приложение. Данные остаются на вашем устройстве.
